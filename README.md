# Student & Library Management System

A beginner-friendly, team-built **C project** focused on managing student records and basic library operations through a simple console application.

## Overview

The goal of this project is to build a small, practical system that brings student record management and library book tracking together in one application. It is being developed as a collaborative first team project, with an emphasis on learning C programming, modular code organization, testing, and Git/GitHub collaboration.

## Planned Features

### Student Records

- Add, view, search, update, and delete student records
- Store basic student information such as roll number, name, branch, and semester

### Library Management

- Add and view books
- Search for books by ID or title
- Issue books to students and record returns
- Track book availability

### Data Persistence

- Save records locally so information can be retained between program runs

## Technology

- **Language:** C
- **Compiler:** GCC
- **Version control and collaboration:** Git and GitHub

## Project Status

**Planning and initial setup.** Features are planned and may change as the team agrees on the design. Build and run instructions will be added when the first working version is available.

## Development Approach

The team plans to build the minimum viable version first, test the main student and library workflows, and add optional enhancements only after the core features work reliably.

## Contributing

This is a collaborative student project. Team members should work on focused changes, use descriptive commit messages, and review changes before merging them into the main branch.
